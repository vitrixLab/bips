# BIP Research Inventory

Private fork research artifact indexing BIP documents from `vitrixLab/bips:master`. Quantitative values are derived from source contents where directly accessible; otherwise they are `UNKNOWN`. Qualitative fields are research classifications, not normative claims.

## Scope

The inventory covers canonical root-level BIP documents named `bip-####.md` or `bip-####.mediawiki` in the fork's `master` branch. The repository index is used for title/type/status metadata where those fields are explicitly published there.

## Research boundaries

This inventory is a fork-only research index. No upstream BIP contribution, issue, comment, review, or merge is implied or requested.

## Evidence principle

A quantitative value is `UNKNOWN` when it cannot be derived directly from accessible source content. A qualitative tag is a classification for research organization, not a claim about normative meaning. The inventory does not infer missing metadata.
